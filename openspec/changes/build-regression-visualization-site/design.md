# 設計：迴歸演算法視覺化網站

## 架構

```text
瀏覽器（React + Plotly.js）
    │ HTTPS /api
    ▼
模型 API（FastAPI + scikit-learn）
    │
    ├── 50 Startups CSV
    └── Boston Housing CSV
```

前端為 SPA，負責控制項、圖表與結果呈現。後端為無狀態 API，讀取受版本控制的資料集、執行前處理與模型訓練，僅回傳 JSON 統計值及繪圖所需資料。資料集規模很小，第一版不需要資料庫或背景佇列。

## 介面流程

1. 使用者選擇資料集。
2. 網站載入欄位摘要與探索圖表。
3. 使用者選擇模型與訓練比例。
4. 前端呼叫模型 API。
5. 後端完成固定亂數種子的切分、前處理、訓練與評估。
6. 前端顯示指標、實際值 vs. 預測值、殘差與特徵解釋。

## 前處理與模型

| 資料集 | 目標欄位 | 前處理 |
| --- | --- | --- |
| 50 Startups | Profit | 對 State 做 one-hot 編碼；數值欄位視模型需要標準化 |
| Boston Housing | MEDV | 數值欄位缺失值檢查；線性模型使用標準化 |

- 每次實驗使用固定 `random_state`，使課堂展示可重現。
- 線性迴歸顯示係數；決策樹與隨機森林顯示特徵重要性。
- 所有指標以測試集計算，避免把訓練表現誤當模型品質。

## API 草案

- `GET /api/datasets`：資料集名稱、欄位與摘要。
- `GET /api/datasets/{id}/exploration`：分布、相關性與繪圖資料。
- `POST /api/experiments`：輸入資料集、模型、訓練比例；輸出評估指標、預測點、殘差與特徵解釋。
- `GET /api/health`：部署健康檢查。

## 部署

- 前端：建置為靜態檔案並發佈到 Sites；`VITE_API_BASE_URL` 在部署環境設定為後端 HTTPS 位址。
- 後端：部署至支援 Python ASGI 的雲端服務，啟用 CORS，僅允許正式前端來源。
- 部署後以 `/api/health`、資料集載入與單次實驗作為 smoke test。
- 自訂網域為後續可選項，不阻擋第一版發佈。

## 風險與處理

- Boston Housing 具歷史資料偏誤與資料集棄用背景：在頁面明確標記其僅供教學與模型示範。
- 免費後端可能冷啟動：前端顯示載入狀態與逾時錯誤提示。
- 前後端不同網域：以 HTTPS、明確 CORS 白名單與環境變數管理 API 位址。

# 提案：建置迴歸演算法視覺化網站

## 為什麼

目前缺少一個可互動操作且可公開分享的作品，來呈現從資料探索、迴歸模型訓練到成效比較的完整資料科學流程。以 Kaggle 50 Startups 與 Boston Housing 為例，可讓使用者直接觀察特徵、模型選擇與預測結果之間的關係。

## 變更內容

- 建置響應式單頁網站，讓使用者可在兩個資料集間切換。
- 提供資料摘要、分布圖、散點圖與相關係數熱圖等探索式視覺化。
- 提供線性迴歸、決策樹迴歸與隨機森林迴歸三種模型。
- 提供訓練／測試比例與模型選擇，顯示 MAE、RMSE、R²、實際值對預測值圖、殘差圖與可解釋性資料。
- 以 Python FastAPI 與 scikit-learn 實作模型 API；以 React 與 Plotly.js 實作使用者介面。
- 將完成的前端部署為可分享網站；後端部署為可由前端呼叫的 HTTPS API，並以環境變數設定 API 網址。
- 在頁面上註明資料來源與 Boston Housing 的資料集背景限制。

## 非目標

- 第一版不支援使用者上傳資料、登入帳號、資料庫保存實驗，或自訂模型程式。
- 第一版不處理分類、深度學習與即時協作功能。
- 不把雲端部署密鑰或 API 金鑰納入原始碼。

## 影響範圍

- 新增前端、後端、資料集與部署設定。
- 前端部署平台需支援 SPA 靜態檔案；後端平台需支援 Python HTTP 服務。
- 會新增對應的套件鎖定檔與環境變數範例檔，但不提交實際祕密值。

## 成功標準

- 使用者可在公開網址中完成資料集切換、探索資料與執行一次模型實驗。
- 對每個資料集與三種模型，網站能回傳且顯示 R²、RMSE、MAE 與至少一張預測結果圖。
- 行動裝置與桌面瀏覽皆可讀取主要操作與圖表。
- 發布版本能從全新瀏覽器工作階段載入，且 API 呼叫不含混合內容或跨網域阻擋。
